How this works

  • Fill in what the catch card shows: species, medal, weight, length, score, the three pieces of gear with their experience %, temperature, bait and time. Every field is free text, so anything the game shows can be written down, whether or not it's in the suggestions.
  • The + next to weight, length and score works like the catch card's: how much this catch beat that angler's previous best of the same species. The first catch of a species counts in full. A catch that didn't beat the record shows no +.
  • The 🕓 beside a text field opens its History: everything that field has held. Click a value to fill it in, add ones by hand (fish you caught before you started logging), or remove any with ×. Saving a catch adds its values to History. Removing from History never touches the logbook.
  • The Species list is every species you've logged, by reserve, with your bests. Click one to start a new catch of it on that reserve.
  • Gear presets remember a rod, reel and bait together. The experience % is still per catch, since it changes every time.
  • Same Spot keeps the form filled after each save, for a run of catches from the same place with the same setup.
  • Timestamp is on by default, so the date is set the moment you save. Turn it off to fill the date in yourself.
  • Already logged a catch and want another like it? Open it, change what differed, and press Save as New.
  • Tick entries and press Copy Selected to put them on the clipboard. Shift-click a second tick box to take everything in between.
  • Units shows the log as typed, or converted to imperial or metric. What you typed is what's kept.

Saving

  • The log saves itself in this browser as you type, including the entry you're part-way through.
  • New starts an empty logbook. Save the current one first if you want to keep it.
  • Save writes it out to a .json file and Open loads one back.
  • Clearing your browser's site data wipes the in-browser copy, so keep a file if the log matters.

Angler Fish Log

An unofficial, non-commercial logbook for Call of the Wild: The Angler. Record what you caught, where, with what, and how it measured up. Not affiliated with, endorsed by, or supported by Expansive Worlds or THQ Nordic.

Nothing here is read from the game. Every field is yours to fill in from the catch card. The suggestion lists for reserves, species, medals, weather, traits and baits come from community sources, credited below, and only ever suggest.

Call of the Wild: The Angler and its names are the property of their owners. The app is modelled on the same author's Monster Hunter Hunting Log apps.

AI Use: Anthropic's Claude Code was used for code generation and code assistance.
